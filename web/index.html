    What this is
    
      
    Tend is a self-hosted MCP server (spec 2025-11-25, Streamable HTTP) that gives Alexa+ a shared, persistent care log for families looking after a parent. It covers dose logging with a double-dose guard, refill forecasting, refills that need two-step confirmation, observations and caregiver handoffs.
    
      
    Self-hosted MCP servers can't be connected to real Alexa+ devices yet, so this page simulates the experience. The assistant's reasoning runs on Amazon Bedrock (Converse API with tool use) and acts only through Tend's MCP tools. Cards are rendered with MCP Apps (ui:// resources) in a sandboxed iframe.
    
      
    Not medical advice. Tend tracks and coordinates care; it doesn't recommend treatment. Unofficial simulator; not affiliated with or endorsed by Amazon.
